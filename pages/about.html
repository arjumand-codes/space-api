About This Project

NASA Space Explorer

A multi-page frontend project by Arjumand Ali built with HTML, CSS, JavaScript, responsive design, API integration, satellite orbit data, localStorage caching, and clean reusable UI components.

Project Overview

Built To Show Real Frontend Skills

NASA Space Explorer is a responsive JavaScript project that uses public NASA APIs and space-data sources to display real space and Earth observation data. The project is designed as a portfolio-ready frontend application with multiple pages, reusable helper functions, clean file structure, API calls, loading states, error handling, and cached results.

The main goal of this project is to show practical frontend development skills instead of only static page design. It proves that the site can connect with external APIs, process JSON data, render dynamic results, and present useful information inside a modern responsive interface.

Project Modules

Pages Included

These modules make the project look complete, useful, and stronger for a frontend developer portfolio.

01

APOD

Loads Astronomy Picture of the Day with image/video support, date picker, random date, metadata, and cache.

02

Asteroids

Shows near-Earth objects with speed, miss distance, size estimate, close approach date, and safe/hazard badge.

03

Search

Searches NASA Image and Video Library without needing a personal API key.

04

EPIC

Displays real Earth images from NASA EPIC with featured image, image gallery, coordinates, and metadata.

05

EONET

Tracks Earth natural events like wildfires, severe storms, volcanoes, floods, droughts, and snow.

06

DONKI

Shows space weather notifications, solar flares, CME events, geomagnetic storms, and solar activity data.

07

Satellites

Searches satellite TLE orbit records by name or NORAD ID and displays orbit line data.

08

Mars

Mars Rover photo gallery module prepared for rover image data and experimental API testing.

Tech Stack

Tools Used

The project is intentionally built without frameworks so the core frontend logic stays clear and easy to understand.

HTML5

Semantic page structure, navigation, sections, forms, cards, and multi-page routing.

CSS3

Responsive layout, modern dark UI, grid, flexbox, animations, and custom components.

JavaScript

Fetch API, async/await, DOM rendering, events, validation, and localStorage cache.

NASA APIs

APOD, NeoWs Asteroids, EPIC, EONET, DONKI, Mars Rover Photos, and Image Search.

TLE Data

Satellite search by name or NORAD ID with Two-Line Element orbit records.

UX States

Loading skeletons, error messages, empty states, badges, filters, and source links.

Responsive

Mobile-first layout behavior with separate responsive CSS rules for smaller screens.

GitHub Ready

Clean folder structure, reusable files, portfolio-focused content, and live deployment support.
