Frontend Features

What This Project Shows

This project is built to look strong on GitHub, portfolio, and live deployment by combining UI design with real API functionality.

01

API Integration

Uses real external APIs with fetch, async/await, JSON parsing, dynamic rendering, and error handling.

02

Responsive UI

Clean card-based layout that works on desktop, tablet, and mobile screens.

03

Local Cache

Uses localStorage to reduce repeat API calls and make repeated loading faster.

04

Modern UX

Includes loading states, error messages, badges, filters, search, date inputs, result grids, source links, and animated visuals.

Project Roadmap

Completed Modules

This dashboard is now structured as a serious frontend project with multiple pages, shared CSS, reusable helpers, and separate JavaScript files for each API module.

Module 01

Homepage Dashboard

Main landing page with hero section, API module cards, APOD preview, features, roadmap, CTA, and footer.

Module 02

APOD Page

Daily astronomy picture page with date picker, random button, video support, metadata, and local cache.

Module 03

Asteroid Tracker

Near-Earth object tracker with speed, size, miss distance, close approach date, and hazardous status.

Module 04

NASA Image Search

Search NASA’s media library by keyword with image/video filters, preset chips, and responsive result cards.

Module 05

EPIC Earth Images

Earth image gallery using NASA EPIC data with featured image, gallery cards, coordinates, and metadata.

Module 06

EONET Events

Natural event tracker for wildfires, storms, volcanoes, floods, snow, droughts, and other Earth observation data.

Module 07

DONKI Notifications

Space weather data module for notifications, solar flares, CME events, geomagnetic storms, and related alerts.

Module 08

Satellite Tracker

TLE orbit data module for searching satellites by name or NORAD ID and displaying two-line element records.

Module 09

Project Documentation

About page with project overview, tech stack, modules, file structure, and frontend development purpose.
